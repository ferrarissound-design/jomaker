# ジョーメーカー

スマホ・タブレット中心の、オリジナル横スクロール・ステージメーカーです。

**編集は分かりやすい2Dグリッド、プレイは恐竜ジオラマ風の2.5D。**  
ステージを作る、保存する、すぐ遊ぶ、共有する、という流れをブラウザーだけで完結させています。

## 現在の完成形

- 48pxグリッドのタッチ対応2Dステージエディタ
- Three.jsを使った2.5Dプレイ画面
- プレイヤーはデフォルメ恐竜
- 地上敵は小型肉食恐竜、空中敵はプテラノドン
- スマホ用左右ボタン＋可変ジャンプ
- 一時停止 / 再開 / リトライ
- iPhone Safari向けの入力残留・長押し選択・ピンチズーム対策
- Undo / Redo、ドラッグ連続配置
- 10〜300マスのステージ長変更
- ステージ背景テーマ
- パーツ個別設定
- localStorage保存
- 未保存編集の自動下書きと復旧
- ステージ共有コード
- 2D Canvasへの安全なフォールバック

2.5D表示ではThree.jsをCDNから動的に読み込みます。WebGLまたはThree.jsの読み込みに失敗した場合、プレイ画面は従来のCanvas 2D表示へ自動的に戻ります。

## 起動

Node.js 22以降で実行します。

```sh
npm run dev
```

ブラウザーで http://localhost:5173 を開きます。

同じネットワークのスマホから確認するときは、PCのLAN IPアドレスのポート5173へアクセスします。OSのファイアウォール設定によっては接続許可が必要です。

`index.html` の直接オープンではなくHTTPサーバーを使用してください。

## 開発コマンド

```sh
npm test
npm run lint
npm run build
npm run preview
```

Playwrightが利用できる環境では、追加のブラウザー回帰チェックも実行できます。

## 作り方

### 配置

パレットからパーツを選び、ステージをタップまたはドラッグします。

同じドラッグ中の連続配置はUndoで1操作として戻せます。

### カメラ移動

「移動」を選んでステージをドラッグします。画面下のスライダーでも横位置を調整できます。

### 削除

「消しゴム」を選んでパーツをタップします。

開始地点はパレットの「スタート」で移動します。スタート地点そのものは通常オブジェクトとは別に保持されます。

### Undo / Redo

最大100操作まで保持します。

名前変更、配置、削除、初期化、ステージ長変更などもUndo対象です。

## ステージ設定

編集画面上部の「ステージ」から設定できます。

- 背景テーマ
- ステージの長さ

ステージ長は **10〜300マス**。

短くすると右端からはみ出したパーツを削除しますが、Undoで戻せます。  
床が端まで続いているステージを長くした場合は、床も自動で延長します。

## パーツ設定

「⚙ 調整」を選んで対象パーツをタップします。

現在個別設定できるもの:

- 大砲
  - 向き
  - 発射間隔
- 動く足場
  - 左右 / 上下
  - 移動距離
  - 速度
- 時間スイッチ
  - 有効時間
- ワープ
  - 接続先

## プレイ

スマホ:

- ◀ 左移動
- ▶ 右移動
- ジャンプ
- ⏸ 一時停止

PC:

- A / D または ← / →
- Space / W / ↑ でジャンプ
- Esc で一時停止 / 再開

ジャンプは押す長さで高さが変わります。

物理更新は120Hz固定ステップで、Coyote TimeとJump Bufferを入れています。

### 一時停止

一時停止すると以下が止まります。

- プレイヤー
- 敵
- 大砲の弾
- 時間ギミック
- 2.5Dアニメーション
- BGM

一時停止メニューから、

- 再開
- リトライ
- 編集に戻る

を選べます。

アプリがバックグラウンドへ移動した場合も、プレイは自動的に一時停止します。

## 保存と自動復旧

正式保存は「保存」ボタンです。

保存済みステージはブラウザーのlocalStorageに保持されます。

編集内容が未保存の場合は、約1秒間隔で別の**復旧用下書き**を自動保存します。

Safariが終了した、タブが破棄された、ページが落ちた、という場合でも、次回トップ画面に復旧カードが表示されます。

正式保存が成功すると下書きは削除されます。

「一覧に戻る」で未保存変更を明示的に破棄した場合も、復旧下書きは削除されます。

ブラウザーのサイトデータ自体を削除した場合は、保存ステージと下書きの両方が消えます。

## 共有

ステージ単位で `JO1.` から始まる共有コードを生成できます。

コードには以下が含まれます。

- ステージ名
- サイズ
- 背景
- スタート位置
- 全パーツ配置
- パーツ個別設定

読み込み時は必ず `validateStage` を通します。

## 主なギミック

### 敵

地上恐竜は足場を歩き、壁や崖で反転します。

プテラノドンは空中を左右に巡回しながら上下に揺れます。

どちらも踏みつけや大砲の弾で倒せます。

### 全滅ドア

ステージ内の地上敵・空中敵がすべて倒れると開きます。

### 大砲

設定した向きへ一定間隔で発射します。

弾は、

- プレイヤーに当たる
- 敵を倒す
- 壊せるブロックを壊す
- 箱を押す
- スイッチを起動する

といった相互作用を持ちます。

### ワープ

複数設置できます。

明示的な接続先を設定しない場合は、配置順の次のワープへ接続します。

### 箱と感圧板

プレイヤーまたは箱が感圧板に乗っている間、圧力ブロックが消えます。

### 時間スイッチ

起動している間だけ時間ブロックが消えます。

有効時間はパーツごとに変更できます。

### チェックポイント

触れた後にミスすると、最後のチェックポイントから復帰します。

## 2.5D描画

`src/render3d.js` がプレイ専用のThree.jsレンダラーです。

ステージデータと物理は2D座標のまま維持し、描画時だけ3D座標へ変換しています。

このため、

- 既存ステージとの互換性
- 2Dエディタの操作性
- 物理ロジックの単純さ

を維持しながら、プレイ画面だけ立体化しています。

PerspectiveCamera、HemisphereLight、DirectionalLight、ソフトシャドウ、立体遠景を使用しています。

スマホ負荷を抑えるため、devicePixelRatioには上限を設けています。

基本のデータフローは、

```text
StageEditor → StageData → GameEngine → Renderer
```

です。

GameEngineは編集データを直接変更しません。

## データ検証

`validateStage` は以下を検証します。

- バージョン
- 名前
- 幅 / 高さ
- 背景ID
- 開始地点
- パーツ種別
- グリッド範囲
- 同一マス重複
- 個別props

ステージ幅は最大300マス、高さは最大40マスです。

## ブラウザー回帰チェック

`scripts/browser-check.js` は、Playwright環境で次を確認します。

- スマホ横
- タブレット
- スマホ縦
- PC
- 配置
- Undo / Redo
- カメラ移動
- 保存 / 再読込
- 共有コード
- プレイ / 編集復帰
- 2点タッチ
- 指をボタン外へ滑らせた時の入力解除
- 一時停止 / 再開
- Esc一時停止
- ズーム禁止viewport
- 未保存表示
- 復旧下書き作成 / 正式保存時の削除
- 横スクロールはみ出し
- ブラウザー例外

CIではNodeの単体テスト、構文検証、静的ビルドを実行しています。

## 制約

- 保存はブラウザーとオリジン単位です
- オンライン共有サーバーはありません
- 2.5D用Three.jsはCDN読み込みです
- WebGL非対応環境では2Dへフォールバックします
- 完全3Dの自由移動やZ軸編集は対象外です

現在の設計は、**「作るときは2Dで簡単、遊ぶときは2.5Dで楽しい」**を優先しています。
