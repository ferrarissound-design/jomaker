# ジョーメーカー

スマホ・タブレットで「つくる → 保存 → すぐ遊ぶ」ができる、オリジナルの2Dアクション＋ステージエディタMVP。画像・音楽・外部フォントへの依存はありません。描画はCanvas、保存はlocalStorage、実行時の外部ライブラリは不要です。

## 起動

Node.js 22以降で、リポジトリ内から実行します。

```sh
npm run dev
```

http://localhost:5173 を開きます。同じネットワークのスマホからは、PCのLAN IPアドレスのポート5173を開いてください（OSのファイアウォール設定に依存します）。`index.html` の直接オープンではなくHTTPサーバーを使用します。

```sh
npm test          # データ・保存・編集・物理・共有・ギミックの23テスト
npm run lint      # 全JavaScriptのNode構文検証（ESLintではありません）
npm run build     # 静的配信用 dist を生成
npm run preview   # dist をローカル配信
```

JavaScript実装のためTypeScript型チェックは未導入です。`src/types.d.ts` は将来の拡張向けデータ契約、`validateStage` は実行時検証です。

## 操作

- **編集**：パレット選択 → マスをタップ／ドラッグ。地面やブロックを指で塗るように連続配置でき、1回のドラッグはUndoでも1操作として扱います。48ワールドpxのグリッドにスナップし、表示上は最低36pxを確保します。
- **移動**：「移動」を選んで上下左右にドラッグ。下のスライダーでも横位置を変更できます。配置と移動は専用ツールで区別します。
- **削除**：消しゴム → マスをタップ。開始地点は「スタート」で移動します。ゴールと開始地点はそれぞれ1つです。
- **戻す**：Undo／Redoは最大100操作。初期化と名前変更も戻せます。
- **保存・共有**：名前を付けて「保存」。一覧から編集・プレイ・共有・複製・削除。共有は `JO1.` から始まるステージコードで、別端末の「共有コード」から読み込めます。更新保存は同じIDを保持します。
- **プレイ**：左右ボタン＋ジャンプを同時押し可能。PCはA/D、矢印、Space/W/↑。ジャンプは短押しで低く、長押しで高くなります。足場は下から通り抜けできます。
- **ミス**：敵・トゲ・落下で開始位置、または最後に触れたチェックポイントへ復帰。コイン・敵もリセットします。敵は壁・崖で反転します。
- **復帰**：「編集に戻る」で編集データ、Undo履歴、カメラ位置を保持。テストプレイは自動保存しません。

横画面を推奨します。縦画面でも編集・プレイが可能です。保存はブラウザーとオリジンごとに独立し、ブラウザーデータの削除で失われます。保存失敗時は通知し、編集中データを保持します。

## 構造と拡張

```text
src/stage.js     StageData検証 / 編集履歴 / localStorageリポジトリ
src/engine.js    StageDataをコピーして動く物理・ゲーム状態（DOM非依存）
src/render.js    Canvas描画（画面外の配置パーツを除外）
src/share.js     バージョン付き共有コードの生成 / 復元
src/app.js       画面遷移・タッチ入力・編集操作・カメラ / 共有UI
src/style.css   タッチ優先UI / Safe Area / 縦横レイアウト
src/types.d.ts  ステージと保存レコードの契約
stages/sample.json  データファイルとして独立したサンプル
```

`StageEditor → StageData → GameEngine` の一方向構造です。エンジンはエディタを参照せず、プレイ中にステージデータを書き換えません。敵・コインなどは別のランタイム状態です。物理は120Hzの固定ステップ、Coyote Timeは110ms、Jump Bufferは130ms。衝突用の地形はグリッドMapで検索します。

標準パーツは地面、ブロック、一方通行足場、動く足場、バネ、壊せるブロック、カギ、トビラ、ON/OFFスイッチ、切替ブロック、ワープ、押せる箱、感圧板、圧力ブロック、大砲、全滅ドア、時間スイッチ、時間ブロック、コイン、トゲ、敵、チェックポイント、スタート、ゴールです。動く足場は左右に往復し、カギはトビラを1枚開けると消費、壊せるブロックは下から頭突きで破壊、スイッチは切替ブロックを出し入れし、複数ワープは配置順で次のワープへ接続します。箱は押して移動でき、箱またはプレイヤーが感圧板に乗る間は圧力ブロックが消えます。敵は上から踏むと倒せ、全滅すると全滅ドアが開きます。大砲は右向きに定期発射し、弾は敵を倒す・壊せるブロックを破壊する・箱を押す・スイッチを遠隔で切り替える相互作用を持ちます。時間スイッチは約3.2秒だけ時間ブロックを消し、大砲の弾からも起動できます。バネは通常ジャンプより高く跳び、チェックポイントはミス後の復帰地点になります。新パーツは`PARTS`・データ契約・検証・描画・エンジンの該当処理へ追加します。共有コードはStageDataをURL-safe Base64化したバージョン付き形式で、`validateStage` を通してから読み込みます。将来は同じStageData契約をオンライン共有やAI生成にも接続できます。

## ブラウザー検証

開発サーバー起動中に、Playwrightを利用できる環境で以下を実行できます。

```sh
node scripts/browser-check.js
```

別の場所にインストールされたPlaywrightは`PLAYWRIGHT_PATH`で指定できます。スマホ横844×390、タブレット1024×768、縦390×844、PC1440×900で配置、Undo/Redo、移動、保存・再読込、共有コード生成、テストプレイ・編集復帰、2点タッチの押下／解放、横あふれ、ブラウザー例外を検証します。スクリーンショットは`artifacts/`に出力します。

Chromiumでの画面・タッチエミュレーションを実施しています。iOS Safari／Android端末の実機検証は未実施です。
